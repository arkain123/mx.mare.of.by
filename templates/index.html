Full domain / mailbox check

Runs every available check in parallel: SPF, DMARC, DKIM, MX, blacklists, SMTP connectivity. Enter a full email address to additionally probe the mailbox via RCPT TO across ports 25, 587, 2525 and 465.



Result

SPF record check

Looks up the domain's TXT SPF record and validates its syntax, mechanisms, and DNS lookup limits (max 10 per RFC 7208).



Result

DMARC record check

Queries the _dmarc subdomain and validates the record's policy tags (p, rua, ruf, pct, ...).



Result

DKIM record check

Looks up <selector>._domainkey.example.com. Leave the selector empty to try ~15 common ones in parallel.



Result

MX lookup

Returns the domain's MX records sorted by priority, and checks whether each mail exchanger accepts a TCP connection on port 25 from this host.



Result

Blacklist check

Resolves the domain to an IPv4 address and queries 12 popular DNSBLs (Spamhaus, SpamCop, Barracuda, SORBS, UCEPROTECT, ...).



Result

SMTP connectivity test

Connects to every MX host on port 25, reads the banner, sends EHLO and reports supported extensions. Note: many VPS providers block outbound port 25.



Result

Mailbox existence check

Performs MAIL FROM:<> + RCPT TO:<address> against the domain's MX hosts (or against a specific server if you provide one), on ports 25, 587, 2525 and 465. Note: catch-all servers always answer 250.

Leave empty to use the domain's MX records.


Result

PTR check

Resolves each MX host to its IPv4 addresses and looks up PTR records for them. A mismatch between the PTR entry and the MX hostname is a common deliverability issue — many receivers penalise it.



Result

TLS certificate check

Connects to each MX host on port 25, performs STARTTLS, and inspects the presented certificate: issuer, expiry, subjectAltName, and hostname match. Note: many VPS providers block outbound port 25.



Result

MTA-STS check

Looks up the _mta-sts TXT record and fetches https://mta-sts.<domain>/.well-known/mta-sts.txt to validate the SMTP MTA Strict Transport Security policy (RFC 8461).



Result

TLS-RPT check

Queries the _smtp._tls TXT record and extracts the rua reporting destinations for SMTP TLS Reporting (RFC 8460).



Result

BIMI check

Looks up default._bimi and validates the v=BIMI1 record (l= logo URL, a= VMC authority). Verifies that the logo is served and returned as SVG.



Result

Role accounts check

Probes postmaster@, abuse@, hostmaster@ and webmaster@ on the domain's primary MX via RCPT TO. postmaster and abuse are required by RFC 2142 — their absence is a real operational problem.

Requires outbound port 25. Probes only the primary (lowest-priority) MX.


Result

Catch-all check

Probes a random non-existent mailbox on the domain's primary MX via RCPT TO. If the server accepts it (250), catch-all is enabled — a common source of backscatter spam and a signal that every typo address reaches a real inbox.

Requires outbound port 25. Probes only the primary (lowest-priority) MX.
